# 제조 전력 예측 · 최적화 (Manufacturing Power Prediction & Optimization)

제조기업 전력사용량 **예측 → 오차분석 → 피크저감방안 제안** 공모전 프로젝트입니다.

## 팀 구성
- **진민정**: 데이터 전처리
- **이소은**: 전력 예측 모델링 (HGB)
- **본인**: 피크 저감 최적화

## 데이터
- 제조 공장 전력 사용 데이터 (15분 단위 피크 전력, 생산량, 기온, 풍속, 습도, 강수량, 공장인원 등)
- 기간: 2021-01-01 ~ 2021-09-14 (총 6,168행)
  - train: 4,272행 (2021-01-01 ~ 06-27)
  - valid: 912행
  - test: 936행 (2021-08-07 ~ 09-14)

## 예측 모델
- **HistGradientBoostingRegressor(HGB)** 기반 전력 예측 (`Best_Way.py`, 이소은 담당)
- 성능: MAE 10.16 / RMSE 14.51 / R² 0.94

## 최적화 (본인 담당)
예측 모델을 바탕으로 **피크 전력(최대수요전력) 저감**을 위한 4가지 최적화 방법을 시도했습니다.

| # | 방법 | 아이디어 | 결과 |
|---|---|---|---|
| 1 | **전력값 재분배** (총생산량 보존) | 생산계획은 그대로 두고, 예측된 전력값을 시간대별 안전상한·전역 피크상한 내에서 LP로 재분배 | 피크 173.08 → **164.00kW로 감소**, 총생산량 보존 — 4개 시도 중 유일하게 수치 개선 확인 |
| 2 | **생산량 재배치** (±20%, CP-SAT) | 시간별 생산량을 80~120% 범위 후보 중에서 바꿔 HGB 예측 피크 초과분을 최소화 | 상한초과분 감소율 0% — 생산량은 피크의 핵심 변수가 아님 |
| 3 | **매칭 최적화** (유사 사례 참조) | 생산량·날씨가 비슷한 과거 시점을 찾아 그 생산량으로 운영했다면 피크가 낮았을지 확인 | 1차: 643건 매칭, 평균개선 25.75 → **HGB 재검증 시 24건(3.7%)·0.43으로 급감** (계절효과 등 미반영 요인 때문으로 판명) |
| 4 | **안전마진 최적화** (Water-filling LP) | train의 과소예측 오차를 24개 시간대에 예산 배분(LP)해 초과분 최소화, test에서 평탄배분과 비교 | 예산 400 이상에서 **평탄배분이 더 우수** — train에서 학습한 시간대별 위험순위가 test에서 재현 안 됨(과적합) |

### 종합 결론
- 생산량·기온·습도가 비슷해도 피크가 크게 다르고, 시간대만으로도 위험 구분이 안 됨.
- **현재 데이터(생산량, 기온, 풍속, 습도, 강수량, 시간변수)에 기록되지 않은 다른 요인**(설비 운전방식, 중복가동, 계절적 기기전환 등)이 피크의 핵심 결정요인일 가능성이 높음.
- 유일하게 수치 개선을 보인 것은 **1. 전력값 재분배**지만, 생산계획과 무관한 전력값 자체 재배열이라 현실 적용성은 제한적임.
- 이는 분석의 실패가 아니라, **데이터 한계를 실험적으로 증명한 결과**로 포지셔닝.

## 실행 방법
1. `requirements.txt` 기준 라이브러리 설치
2. `optimization_HGB.ipynb`를 Jupyter에서 열고 **Cell → Run All**
   - 첫 셀의 `%run Best_Way.py`가 데이터 전처리~예측까지 전부 수행
   - 이후 셀들이 순서대로 1~4번 최적화를 재현
